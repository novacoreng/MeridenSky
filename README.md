# Meridian Sky

Luxury lifestyle and social experience website.

## Build direction

Built from the Meridian Sky PRD/TRD using the NOVA UI/UX direction: cinematic editorial layouts, large photography, refined typography, restrained motion, high-contrast dark palette and strong conversion points.

## Current phase

Phase 1 establishes the production Next.js foundation and the cinematic homepage shell.

## Run

```bash
npm install
npm run dev
```
